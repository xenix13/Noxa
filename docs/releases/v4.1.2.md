## Noxa 4.1.2

### Fixes

- **Continue watching:** a new episode of a show you follow could be missing from *Continue watching*. Only the twelve shows with the most recently finished episode were checked for a next episode, before knowing whether any episode was left to watch. Finishing episodes of a dozen other shows (or marking them watched) pushed the rest out, and the row could even end up empty. Finished shows are now left out first, so every show with an episode still to watch is considered.
- **Photos:** at the root of the *Albums* tab, the header said "0 photos" when the library only has albums; it now shows the number of albums.

### Installation

- **Proxmox VE helper script** (draft for the community-scripts catalogue, in `deploy/proxmox-helper-scripts`): the container is privileged with `mount=cifs`, so Noxa can mount NAS shares itself, and the mount service is started at install and restarted after an update.
- **Unraid:** new template (`deploy/unraid/noxa.xml`) and an Unraid section in the installation guide.

### Project

- The README opens with a short tour of the app.
- CI: the ffmpeg packages are cached and the apt mirror switch works, so slow Ubuntu mirrors no longer break the test job.
