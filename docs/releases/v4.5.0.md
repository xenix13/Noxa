## Noxa 4.5

> **Android and Android TV apps: reinstall once.** The apps changed their internal id, so Android installs the 4.5 apps next to the old ones instead of updating them. Install the new app, sign in again, then uninstall the old one. On the phone, offline downloads have to be downloaded again. The old apps keep working with a 4.5 server until then. Details in [Apps → Updates](../apps.md#updates).

### New

- **Sort by last watched** in libraries, an ascending / descending button for every sort, and the sort remembered per library in your account (#14).

### Under the hood

- The code was renamed from its old internal names (`seance`, `Nexis`) to `noxa`, with no change for existing servers:
  - **Environment variables** are now `NOXA_…`; the old `SEANCE_…` names still work.
  - **New backup files** start with `noxa-`; `nexis-` backups are still listed and restored.
  - Servers that are not updated yet still see this update.
