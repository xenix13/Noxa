## Noxa 4.5

> **Android and Android TV apps: reinstall once.** The apps changed their internal id, so Android installs the 4.5 apps next to the old ones instead of updating them. Install the new app, sign in again, then uninstall the old one. On the phone, offline downloads have to be downloaded again. The old apps keep working with a 4.5 server until then. Details in [Apps → Updates](../apps.md#updates).

### New

- **Sort by last watched** in libraries, an ascending / descending button for every sort, and the sort remembered per library in your account (#14).

### Faster video conversion

- **Software conversion is about 17 % faster.** The benchmark showed Noxa converting slower than Jellyfin and Plex. Noxa now uses lighter x264 analysis settings, the same trade-off Jellyfin makes. Measured with the benchmark kit on 2 CPU cores (HEVC 10-bit 1080p → H.264 720p): 3.13× real time before, 3.65× now, against 3.56× for Jellyfin on the same machine. The picture quality is the same (SSIM 0.946 in both cases). The stream can be a little bigger, but it never goes over the bandwidth limit of the chosen quality.
- **Converted videos start sooner on a fast server.** The player used to wait for 20 seconds of video before starting a converted stream (10 after a seek). It now measures how fast the video arrives: at 2.5× real time or more it starts with 6 seconds, at 1.6× or more with 10. A slow server keeps the longer wait, which avoids stalls in the first minutes.

### Online demo

- **Try Noxa without installing it:** https://xenix13.github.io/Noxa/ — the real interface on a few free films (30-second clips). Nothing is saved, and the administration can be browsed but not changed.

### Under the hood

- The code was renamed from its old internal names (`seance`, `Nexis`) to `noxa`, with no change for existing servers:
  - **Environment variables** are now `NOXA_…`; the old `SEANCE_…` names still work.
  - **New backup files** start with `noxa-`; `nexis-` backups are still listed and restored.
  - Servers that are not updated yet still see this update.
