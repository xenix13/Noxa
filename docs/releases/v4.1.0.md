## Noxa 4.1.0

### Discover, closer to Seerr

- **Upcoming movies and shows**, plus popular movies and popular shows, as new rows on the Discover page.
- **Shortcuts** at the top (Trending, Upcoming movies, Upcoming shows, Popular…) and a full list for each, with filters by type, sorting, **genre** and streaming service.
- **Request from the card:** a "+" button on each poster requests the title without leaving the list (seasons are still asked for a show), so several titles can be requested in a row.
- **Search** shows results while you type, grouped into Movies and Shows, most popular first.

### Navigation

- **Back button** in the top bar, in the desktop app and in browsers too (it used to exist only in the installed web app). Going back reopens the previous page where you left it.
- **Continue watching:** a discreet "i" button on each card opens the show or movie page instead of resuming playback.
- **Full screen is kept** when the next episode starts, automatically or with the Next button.

### Fixed

- Marking an episode as watched no longer makes the page jump to the top for a moment.
- A stray "null" text at the bottom of Discover lists.
