## Noxa 4.5.1

A fix release.

### Fixes

- **An external subtitle replaced under the same name kept its old timing** (#24). When a `.srt` next to a video was replaced by a better synced version with the same name, Noxa kept serving the old one, and the browser kept it for an hour too. Noxa now notices that the subtitle file changed, and the player checks the subtitles again at each playback. This also covers a subtitle added to the folder later, which can change the order of the external subtitles.
