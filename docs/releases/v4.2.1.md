## Noxa 4.2.1

A fix release.

### Fixes

- **Movies sharing a folder:** when a movie left a folder that holds several movies (a collection folder such as *Marvel*) at the same time as another one arrived, the new movie could take over the old one's page, watched state and ratings. Since 4.1.4, a file only replaces another when it is the same movie (same title and year), as with a Radarr upgrade.
