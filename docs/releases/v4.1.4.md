## Noxa 4.1.4

A fix release.

### Fixes

- **Radarr / Sonarr upgrades:** when Radarr or Sonarr replaces a file with a better copy, the new file takes over the existing movie or episode. It used to be added as a new episode, so it showed up as unwatched and was announced as *New episode*. Watched state, ratings, lists and metadata are now kept. If the old file is deleted while the new one is still being copied, the title is kept until the copy is finished.
  - Episodes that already lost their watched state this way have to be marked as watched again.
- **Home banner:** *A random title (changes every hour)* kept showing the same title. It now changes every hour. The *Short movies* row, which had the same problem, now changes every day.
- **Dialog buttons:** on a narrow window, the buttons wrap onto a second line instead of being cut off. In the theme editor, *Cancel* was hidden.
