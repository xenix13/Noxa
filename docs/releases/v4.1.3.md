## Noxa 4.1.3

### Changes

- **Watchlist:** a show now leaves *To watch* once you have watched every episode, like movies already did once watched. Specials (season 0) do not count, since they are often skipped. Shows already finished are removed from the list when the server updates. If a new episode comes out later, the show is still followed: notifications and *Continue watching* go on as before.
- **Trakt sync:** a finished show that is still in the Trakt watchlist is no longer added back to *To watch*.

### Language

- **English by default for new servers.** Before setup, the interface follows the browser's language: French for a French browser, English for everything else. The language chosen at setup becomes the server's language as before. Existing servers keep theirs.
- **Install scripts in English:** `install.sh`, `proxmox-lxc.sh`, the system setup script and the comments of `docker-compose.yml` and the `Dockerfile`. The update progress shown in the interface recognises both the old French messages and the new English ones.

### Project

- The test accounts use neutral names.
