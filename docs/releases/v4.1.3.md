## Noxa 4.1.3

### Changes

- **Watchlist:** a show now leaves *To watch* once you have watched every episode, like movies already did once watched. Specials (season 0) do not count, since they are often skipped. Shows already finished are removed from the list when the server updates. If a new episode comes out later, the show is still followed: notifications and *Continue watching* go on as before.
- **Trakt sync:** a finished show that is still in the Trakt watchlist is no longer added back to *To watch*.
