## Noxa 4.1.1

### Security

- **Desktop app build tools:** `minimatch` is forced to 11.0.8 (fixes a denial-of-service issue reported by Dependabot). It only affects the machine that builds the apps, not the installed apps.
- **CodeQL findings:**
  - The OpenSubtitles API host is now compared exactly instead of by prefix.
  - The daily wallpaper pick uses SHA-256 instead of SHA-1 (it was never security-related).
  - A test regular expression no longer depends on letter case.
  - The DLNA discovery socket listening on all interfaces is intended (TVs must find the server); requests from outside the local network are refused and DLNA is off by default.

### Project

- `docker-compose.yml` uses the `latest` image on every branch; use `:test` by hand to try the test channel.
